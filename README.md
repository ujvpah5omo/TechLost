# 全科技蓝图解锁

这是一个《饥荒联机版》服务器 Mod。所有科技配方初始只能通过蓝图解锁；玩家学习蓝图后可自行制作，也可以把自己掌握的配方带进新建的科技站。

## 功能

- 科学、魔法、远古、月岛、暗影、书本等科技树配方初始只能通过蓝图学习。
- 无需科技的基础配方保持原有制作方式。
- 同时作用于原版配方和其他 Mod 注册的配方。
- 被限制的配方只能通过对应蓝图学习，学习后该玩家可以正常制作。
- 已学习该配方的玩家在某个对应科技站制作一次后，该配方只会公开到这一台科技站；其他玩家随后必须靠近同一台科技站才能制作并学会。
- 已学习配方的玩家建造科技站时，会把这台科技站能支持的已知配方直接公开到这台站，不需要再在新站旁制作一次。
- 每个建造或生成出来的科技站都会独立保存公开进度。新建的科学机器、炼金引擎、远古塔、书柜等不会继承其他同类科技站的进度，除非建造者已经掌握可由该站支持的配方。
- 科技站、角色科技、薇克巴顿书柜及其他特殊原型站均不能直接解锁受限配方。
- 所有被限制的科技配方都会自动加入风滚草蓝图池，保证存在获取途径。
- 可配置风滚草额外掉落蓝图的概率，最低为 `1%`。
- 角色/技能专属、标记为不可解锁、禁止蓝图或缺少有效名称的特殊配方不会进入蓝图池，并保留原本解锁方式。
- 原版通用蓝图因 `TECH.LOST` 候选池为空时，会自动改为本 Mod 的有效蓝图，不再生成“未知蓝图”。

本 Mod 将所有非空科技需求统一替换为游戏原生的 `TECH.LOST`。蓝图学习后，配方会进入角色的已知配方列表，从而允许该玩家正常制作；当已学习该配方的玩家在某一台对应科技站制作成功，或建造了一台能支持该配方的科技站时，配方会加入这一台科技站的公开列表。其他玩家通过这台站制作后也会真正学会该配方。

## 安装

将整个文件夹放入《饥荒联机版》的 `mods` 目录，在创建或编辑世界时启用本 Mod，然后按需设置风滚草蓝图概率。

配置变更后重新进入世界生效。

风滚草每次命中概率后最多额外掉落一张蓝图，并在所有受限制的配方中等概率选择。默认概率为 `5%`，最低为 `1%`；即使旧世界曾将掉落设为关闭，升级后也会按 `1%` 生效。
