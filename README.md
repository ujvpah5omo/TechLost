# 全科技蓝图解锁

这是一个《饥荒联机版》服务器 Mod。符合条件的普通科技配方初始只能通过蓝图解锁；玩家学习蓝图后可自行制作，也可以把自己掌握的配方带进新建的科技站。原生稀有蓝图继续使用原版获取渠道。

## 功能

- 科学、魔法、月岛、暗影、书本等科技树配方初始只能通过蓝图学习。
- 原生 `TECH.LOST` 稀有配方不会加入风滚草蓝图池，继续通过 Boss、任务、商店及世界交互等原版渠道获取。
- 可配置是否将受技能树限制的可制作配方加入高级蓝图池；默认关闭并保留原版解锁方式，开启后沉底宝箱按开启者角色筛选，海盗宝藏按挖开者角色筛选，且仍需激活对应技能才能学习和制作。
- 可分别配置是否将远古伪科学站、辉煌铁匠铺和暗影操纵基座配方加入蓝图池；三个选项均默认关闭并保留原版制作方式。开启后需先学习蓝图，且学会后仍只能靠近满足原始科技等级的对应科技站制作。
- 无需科技的基础配方保持原有制作方式。
- 同时作用于原版配方和其他 Mod 注册的配方。
- 被限制的配方只能通过对应蓝图学习，学习后该玩家可以正常制作。
- 可配置角色死亡时是否丢失全部已学习配方；默认关闭，开启后死亡会清除配方知识。
- 已学习该配方的玩家在某个对应科技站制作一次后，该配方只会公开到这一台科技站；其他玩家随后必须靠近同一台科技站才能制作并学会。
- 已学习配方的玩家建造科技站时，会把这台科技站能支持的已知配方直接公开到这台站，不需要再在新站旁制作一次。
- 每个建造或生成出来的科技站都会独立保存公开进度。新建的科学机器、炼金引擎、远古塔、书柜等不会继承其他同类科技站的进度，除非建造者已经掌握可由该站支持的配方。
- 科技站、角色科技、薇克巴顿书柜及其他特殊原型站均不能直接解锁受限配方。
- 无角色归属的普通受限科技配方会自动加入风滚草蓝图池，并按基础、进阶、高级固定分层抽取；角色相关蓝图主要通过沉底宝箱、海盗宝藏和海盗猴首领大副等触发者奖励获得。
- 未开启活动时，对应的万圣夜、冬季盛宴及生肖活动科技不会进入蓝图池。
- 可配置风滚草额外掉落蓝图的概率，最低为 `1%`。
- 标记为不可解锁、禁止蓝图或缺少有效名称的特殊配方不会进入蓝图池，并保留原本解锁方式；角色标签专属配方可通过配置加入高级蓝图池。
- 原版通用蓝图也会按本 Mod 配置过滤；命中 `TECH.LOST` 空池或被排除的技能配方时，会自动改为有效蓝图。

本 Mod 将符合条件的普通非空科技需求统一替换为游戏原生的 `TECH.LOST`，但不会改动原本就是 `TECH.LOST` 的稀有配方。蓝图学习后，配方会进入角色的已知配方列表，从而允许该玩家正常制作；当已学习该配方的玩家在某一台对应科技站制作成功，或建造了一台能支持该配方的科技站时，配方会加入这一台科技站的公开列表。其他玩家通过这台站制作后也会真正学会该配方。

## 安装

将整个文件夹放入《饥荒联机版》的 `mods` 目录，在创建或编辑世界时启用本 Mod，然后按需设置技能树与特殊科技站蓝图、死亡科技惩罚和风滚草蓝图概率。

配置变更后重新进入世界生效。

风滚草每次命中概率后最多额外掉落一张蓝图，并在普通蓝图池中按固定分层抽取：基础 `42%`、进阶 `48%`、高级 `10%`。默认概率为 `5%`，最低为 `1%`；即使旧世界曾将掉落设为关闭，升级后也会按 `1%` 生效。

## 配置项说明

### 技能树配方蓝图

默认：关闭。

开启后，受角色技能树限制的“可制作配方”会进入高级蓝图池。沉底宝箱按开启者当前角色筛选，海盗宝藏按挖开者当前角色筛选这类角色相关奖励，不会抽到其他角色的技能树配方。玩家仍然需要按原版规则点亮对应技能，才能学习和制作这些配方。带有月亮线或暗影线条件的技能配方，还会继续受对应裂隙开启状态限制。

### 技能树许可蓝图

默认：关闭。

开启后，技能树节点需要先获得技能许可点。玩家学习对应角色的技能许可蓝图后，该角色获得 `1` 个技能许可点；之后玩家可以自己选择任意当前可点的受控技能节点，并仍然需要消耗原版技能点、满足原版前置条件手动点亮。

可选模式：

- 关闭：不限制技能树节点，按原版方式点亮。
- 开启：技能树节点需要技能许可点，许可点蓝图不进入普通蓝图池，只由海盗猴首领大副掉落。
- 月后影后：技能树节点仍然需要技能许可点，许可点蓝图仍只由海盗猴首领大副掉落；双裂隙开启前，即使已经获得许可点，也不能点亮技能。

开启该配置后，海盗猴首领大副死亡时会掉落击杀者角色对应的技能许可蓝图。大副奖励不会挤占风滚草和普通海盗猴的普通蓝图池；如果无法识别击杀者，则不会回退为其他在线角色的许可蓝图。击杀者角色已经没有可用许可空间时，许可蓝图仍然可以继续掉落，玩家可以自行保存。月后影后模式下，可以提前获得许可点，但在双裂隙开启前仍然不能实际点亮技能。节点自身的月亮/暗影裂隙条件仍然保留。

技能许可蓝图不绑定玩家，但学习者必须正在使用蓝图对应的角色。技能许可点按角色记录。换角色时，未使用的许可点会被重置；成功点亮技能会消耗 `1` 个许可点，并永久许可这一个被点亮的节点。取消技能或重置技能树不会把它返还成可重新分配的许可点。

### 角色专属科技蓝图

默认：关闭。

开启后，非技能树、且需要科技站的角色专属配方会进入高级蓝图池。沉底宝箱按开启者当前角色筛选，海盗宝藏按挖开者当前角色筛选角色相关奖励，不会抽到其他角色的专属配方。只有对应角色可以学习这些蓝图。禁用角色的专属配方不会进入蓝图池。

### 远古塔科技蓝图

默认：关闭。

开启后，远古伪科学站配方会进入蓝图池。学习蓝图后，玩家仍然需要靠近对应远古塔才能制作。

### 辉煌铁匠铺科技蓝图

默认：关闭。

开启后，月亮裂隙开启后，辉煌铁匠铺配方才会进入蓝图池。学习蓝图后，玩家仍然需要靠近辉煌铁匠铺才能制作。

### 暗影操纵基座科技蓝图

默认：关闭。

开启后，暗影裂隙开启后，暗影操纵基座配方才会进入蓝图池。学习蓝图后，玩家仍然需要靠近暗影操纵基座才能制作。

### 沉底宝箱高级蓝图

默认：关闭。

开启后，沉底宝箱会在首次打开时额外产出高级科技蓝图。`traveler` 和 `splunker` 类型沉底宝箱会稳定给高级蓝图；如果沉底宝箱中出现黄宝石或绿宝石等高价值奖励，还会额外给高级蓝图。其他沉底宝箱按配置概率给图。角色相关奖励会按开启者当前角色筛选。

### 海盗宝藏高级蓝图

默认：关闭。

开启后，如果海盗宝藏包含沉底宝箱内容，会额外给 1 张高级蓝图。普通海盗宝藏则按配置概率给高级蓝图。角色相关奖励会按挖开者当前角色筛选。

### 死亡丢失科技

默认：关闭。

开启后，玩家角色死亡会清空该玩家已学习的配方。科技站已经公开的配方不会因此丢失。

### 海盗猴蓝图掉落

默认：开启。

开启后，普通海盗猴死亡时，会按风滚草蓝图概率掉落普通蓝图池中的蓝图，并使用同样的基础 `42%`、进阶 `48%`、高级 `10%` 分层抽取规则，不包含角色相关奖励和技能许可蓝图。这个设计用于在关闭或很少探索风滚草区域时，给普通蓝图提供额外获取渠道。

### 地面蓝图雨水冲刷

默认：3 次雨。

只影响本 Mod 蓝图池生成的蓝图，不影响原版蓝图。蓝图丢在地上时，每次开始下雨都会计数一次；达到配置次数后会消失。蓝图放进背包、箱子等容器时会暂停计数，拿回地上后继续按之前记录的雨水次数计算。

### 风滚草蓝图概率

默认：`5%`。

每株风滚草被采集时，额外掉落一张受限科技蓝图的概率。最低为 `1%`，最高可以设置为必出。
